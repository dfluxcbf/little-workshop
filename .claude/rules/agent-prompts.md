# Agent task prompts

The templates in `src/agent/templates/prompts/` are the prompt of every unattended Claude task little-workshop
runs, in every project. Changing one changes every task, so update `shared_project_standards/agent_task_standard.md`
in the same change, and keep the two saying the same thing.
